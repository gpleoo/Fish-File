2. Dati Raccolti

Fish File raccoglie e tratta le seguenti categorie di dati:

2.1 Dati forniti volontariamente dall'utente

  • Dati delle sessioni di pesca: data, ora, località, condizioni meteo, note personali
  • Dati delle catture: specie, lunghezza, peso, foto, posizione GPS
  • Preferenze dell'applicazione: lingua, unità di misura, tema

2.2 Dati raccolti automaticamente

  • Dati di geolocalizzazione: posizione GPS (solo con consenso esplicito)
  • Dati vocali: registrazioni audio temporanee per l'assistente vocale (solo con consenso esplicito)

3. Finalità del Trattamento

I tuoi dati vengono trattati per le seguenti finalità:

  • Funzionamento dell'app: permetterti di registrare e visualizzare le tue sessioni di pesca
  • Geolocalizzazione: registrare la posizione delle tue catture sulla mappa
  • Assistente vocale: convertire i comandi vocali in testo per facilitare l'inserimento dati
  • Statistiche personali: fornirti analisi e statistiche sulle tue attività di pesca

4. Base Giuridica del Trattamento

Il trattamento dei tuoi dati si basa su:

  • Consenso (Art. 6.1.a GDPR): per geolocalizzazione e accesso al microfono
  • Esecuzione contrattuale (Art. 6.1.b GDPR): per il funzionamento base dell'applicazione
  • Interesse legittimo (Art. 6.1.f GDPR): per migliorare l'esperienza utente

5. Conservazione dei Dati

Archiviazione locale: Tutti i tuoi dati vengono salvati localmente sul tuo dispositivo utilizzando localStorage del browser. Non trasferiamo i tuoi dati su server esterni.

I dati vengono conservati finché:

  • Non decidi di eliminarli manualmente dall'app
  • Non utilizzi la funzione "Elimina tutti i dati" nelle impostazioni
  • Non cancelli i dati del browser/app

6. Condivisione dei Dati

Fish File non condivide i tuoi dati personali con terze parti. I tuoi dati rimangono esclusivamente sul tuo dispositivo.

Eccezioni:

  • Servizi di mappa: Utilizziamo OpenStreetMap/Leaflet per visualizzare le mappe. Questi servizi potrebbero raccogliere dati tecnici secondo le loro policy.
  • Speech Recognition: L'assistente vocale utilizza le API del browser che potrebbero elaborare l'audio secondo le policy del produttore del browser.

7. I Tuoi Diritti

In conformità con il GDPR, hai i seguenti diritti:

  • Diritto di accesso (Art. 15): puoi richiedere una copia dei tuoi dati
  • Diritto di rettifica (Art. 16): puoi correggere i dati inesatti
  • Diritto alla cancellazione (Art. 17): puoi eliminare i tuoi dati in qualsiasi momento
  • Diritto alla portabilità (Art. 20): puoi esportare i tuoi dati in formato leggibile
  • Diritto di revoca del consenso (Art. 7.3): puoi revocare i consensi in qualsiasi momento

Puoi esercitare questi diritti direttamente dall'app nella sezione Impostazioni → Privacy e Dati, oppure contattandoci all'indirizzo email indicato sopra.

8. Sicurezza dei Dati

Adottiamo le seguenti misure per proteggere i tuoi dati:

  • Archiviazione locale sul dispositivo (nessun trasferimento su server)
  • Nessuna raccolta di dati sensibili non necessari
  • Accesso ai sensori (GPS, microfono) solo con consenso esplicito

9. Cookie e Tecnologie Simili

Fish File utilizza localStorage del browser per salvare:

  • Le tue sessioni di pesca e catture
  • Le tue preferenze (lingua, tema, unità di misura)
  • I tuoi consensi privacy

Non utilizziamo cookie di tracciamento o di profilazione.

10. Minori

Fish File non è destinata a minori di 16 anni. Non raccogliamo consapevolmente dati di minori. Se sei un genitore e ritieni che tuo figlio ci abbia fornito dati personali, contattaci per la rimozione.
